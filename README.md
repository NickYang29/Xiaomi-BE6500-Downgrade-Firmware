# Xiaomi-BE6500-Downgrade-Firmware
 小米路由器BE6500 固件降级1.0.64>>1.0.43
 参考https://www.right.com.cn/forum/thread-8459209-1-1.html
 
小米路由器BE6500 v1.0.64已无法通过xmir打开ssh，请勿升级

先说思路：在升级过程中断电，搞坏文件系统，路由器无法启动，再通过官方修复工具降级。

1，平刷v1.0.64版本，在修复工具固件传输进度条结束后开始计时，12s（或者10s）左右断电（为了破坏第二分区系统），断电后需马上再次进入官方恢复流程，再次做升级动作（相同版本升级），在修复工具固件传输进度条结束后开始计时，5s(或者3s)左右断电（为了破坏第一分区系统）。一定要按照先破坏OS2再破坏OS1顺序。如果OS1  OS2均被破坏。可以通过观察灯来确认路由器在不停重启。黄灯亮一会儿就熄，这样循环。

2,旧版固件1.0.43下载地址，https://cdn.cnbj1.fds.api.mi-img.com/xiaoqiang/rom/rn02/miwifi_rn02_firmware_f7df7_1.0.43.bin,下载后改名miwifi_rn02_firmware_10c85_1.0.65，就是版本号大于现有版本，接下来就可以通过官方修复工具进行降级了，刷入后没有马上亮橙灯，等一会儿白色灯亮起就说明成功了
